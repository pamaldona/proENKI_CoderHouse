Oracle 23ai

Lo nuevo de Oracle 23ai

Oracle Database 23ai marcó el inicio de la integración nativa de inteligencia artificial en Oracle, facilitando el desarrollo moderno con datos vectoriales, JSON y grafos.

  • AI Vector Search: Introducción del tipo de dato VECTOR para búsquedas semánticas y sistemas RAG.
  • JSON Relational Duality: Vistas que permiten leer y escribir los mismos datos tanto en formato JSON como relacional.
  • Property Graphs (SQL/PGQ): Consultas de grafos de propiedades directamente usando sintaxis SQL estándar.
  • Productividad y seguridad: Tipo de dato BOOLEAN, SELECT sin cláusula FROM, True Cache y SQL Firewall integrado.

Oracle 26ai

Lo nuevo de Oracle 26ai

Oracle AI Database 26ai es la versión de soporte a largo plazo (LTS) diseñada para integrar inteligencia artificial directamente en el motor de datos, tanto en la nube como en entornos locales.

  • AI Vector Search: Búsqueda por similitud y consultas híbridas que combinan vectores, texto y datos relacionales.
  • Select AI y Agentes: Consultas en lenguaje natural y creación de agentes de IA dentro de la base de datos.
  • JSON Relational Duality: Flexibilidad para trabajar con los mismos datos como documentos JSON o tablas relacionales.
  • Mejoras en SQL y seguridad: Soporte nativo para tipo BOOLEAN, True Cache para lecturas rápidas y cifrado post-cuántico.

SQL Server 2025

Lo nuevo de SQL Server 2025

SQL Server 2025 integra inteligencia artificial nativa en el motor relacional de Microsoft, mejorando el desarrollo moderno, la analítica en tiempo real y el rendimiento empresarial.

  • Vectores e IA nativa: Tipo de dato VECTOR con índices DiskANN para búsquedas semánticas y conexión directa a modelos externos desde T-SQL.
  • T-SQL moderno: Soporte nativo para expresiones regulares (RegEx), tipo de dato JSON con indexación y llamadas a APIs REST.
  • Analítica en tiempo real: Replicación directa hacia Microsoft Fabric (Fabric Mirroring) y transmisión de eventos con Change Event Streaming.
  • Rendimiento y ediciones: Bloqueo optimizado, compresión ZSTD para backups y mayor capacidad en Standard Edition (hasta 32 núcleos y 256 GB de RAM).

SQL Server 2022

Lo nuevo de SQL Server 2022

SQL Server 2022 es la versión más conectada con la nube de Microsoft, diseñada para integrar servicios de Azure, mejorar la inteligencia de consultas y reforzar la seguridad de los datos.

  • Conexión con Azure: Recuperación ante desastres con Azure SQL Managed Instance, analítica casi en tiempo real con Azure Synapse Link y gobierno de datos con Microsoft Purview.
  • Query Store e inteligencia: Query Store habilitado por defecto y optimización inteligente de planes de ejecución sensibles a parámetros (PSP).
  • Seguridad con Ledger: Funcionalidad de libro mayor inmutable que permite verificar criptográficamente la integridad de los datos contra manipulaciones.
  • Virtualización y T-SQL: Soporte para almacenamiento compatible con S3 mediante PolyBase y nuevas funciones T-SQL para JSON y series temporales.

Oracle Key Vault 21.15

Lo nuevo de Oracle Key Vault 21.15

Oracle Key Vault 21.15 es una actualización enfocada en reforzar la seguridad, estabilidad y mantenimiento de toda la pila tecnológica que protege claves maestras TDE, wallets, certificados y secretos empresariales.

  • Parches críticos de seguridad: Incorpora las correcciones del Critical Patch Update (CPU) de julio de 2026 tanto para el appliance servidor como para el software de endpoints.
  • Base de datos embebida actualizada: Actualiza el motor interno de Oracle Database al Release Update 19.32 para mejorar la protección y el rendimiento.
  • Componentes integrados al día: Incluye actualizaciones de seguridad y estabilidad para Oracle APEX, ORDS, Oracle Java SE y Oracle GoldenGate.
  • Sistema operativo reforzado: Aplica parches de seguridad sobre Oracle Linux 8.10 y mejoras generales de fiabilidad en la plataforma.
